# 美術需求與 ChatGPT 提示詞

目前場上的角色是「麻將館頭像 + 程式畫的身體」，已經可以玩。下面這些圖畫好之後放進去，遊戲會自動換掉，不用改程式邏輯。

優先順序：**角色全身 sprite** ＞ 背景 ＞ 標題 Logo。

---

## 1. 角色全身 sprite（每個角色 8 個姿勢）

### 規格

| 項目 | 要求 |
| --- | --- |
| 姿勢 | `idle` 站立、`run1` `run2` 跑步兩格、`jump` 跳躍、`spike` 空中扣殺、`dive` 飛撲、`win` 勝利、`lose` 沮喪 |
| 方向 | **一律面向右邊**（右邊場地的角色遊戲會自動左右翻轉） |
| 背景 | 透明 PNG |
| 比例 | Q 版，大約 2.5 頭身（頭很大，跟皮卡丘打排球一樣圓滾滾） |
| 服裝 | 沙灘排球裝：上衣用角色原本的代表色，配短褲、運動鞋 |

### 建議做法：一個姿勢一張圖

ChatGPT 很難一次畫出格子對齊的 sprite sheet，所以**一次只畫一個姿勢**，最後用腳本組起來：

1. 開一個新對話，**上傳該角色的頭像**（`public/characters/<id>/normal.png`）。
2. 先貼「角色設定提示詞」，畫出 `idle`，滿意之後再在同一個對話裡依序要其他姿勢（同一個對話，外觀比較一致）。
3. 存成 `art/<id>/idle.png`、`art/<id>/run1.png`…（檔名照上表）。
4. 組成 sprite sheet：

```bash
python scripts/make_sheet.py art/xiaocui public/sprites/xiaocui.png
```

5. 到 `src/lib/game/characters.js` 把該角色加上 `sprite: true`。

> 先做一個角色試試看（建議小春，她本來就穿運動服），確認大小、風格 OK 再做其他人。

### 後續姿勢（同一個對話接著要）

```text
同一個角色、同樣的畫風、大小和服裝，改畫成「{姿勢}」，一樣面向右邊、透明背景、全身入鏡：
```

| 檔名 | 姿勢描述 |
| --- | --- |
| `run1` | 往右跑步，右腳在前、左腳往後踢，雙手擺動 |
| `run2` | 往右跑步，左腳在前、右腳往後踢（跟上一張相反） |
| `jump` | 往上跳起，雙腿縮起、雙手往上伸 |
| `spike` | 空中扣殺，身體後仰、右手高舉用力往前揮下 |
| `dive` | 往右飛撲救球，身體幾乎貼地水平、雙手往前伸長 |
| `win` | 勝利，跳起來比 V 或高舉雙手，表情超開心 |
| `lose` | 輸了，垂頭喪氣坐在地上或彎腰，表情沮喪 |

## 2. 背景（選用）

放到 `public/bg/court.png`，然後把 `src/lib/game/render.js` 的 `USE_BACKGROUND_IMAGE` 改成 `true`。

```text
畫一張 16:9（1920×1080）的 2D 橫向遊戲背景：台灣的海邊沙灘排球場。
- 風格：90 年代日本賽璐璐動畫背景，明亮晴天
- 構圖：下方 15% 是平坦的沙地（角色站的地方，保持平整、不要有東西），中間是海和遠方的山，左邊遠處可以看到台北 101 的剪影
- 畫面正中央「不要」畫球網（遊戲會自己畫）
- 不要人物、不要文字
```

注意：遊戲的地面在畫面由上往下約 87% 的位置（`GROUND = 470`，畫面高 540）。
