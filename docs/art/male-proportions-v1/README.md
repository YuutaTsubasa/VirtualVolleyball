# 男角比例修正版 — 六種畫風・144 張動作圖

使用者已確認金爺、雷歐、阿烈的 90 年代站姿修正版，並明確要求「補齊六種風格與動作」。本包將先前樣張推進正式角色動作製作。

## 內容

六種畫風 anime90、pc98、msdos、taiwan-print、gameboy、modern-paint；三角色 jinye（金爺）、leo（雷歐）、alie（阿烈）；各 idle、run1、run2、jump、spike、dive、win、lose 八張，共 144 張 512×512 RGBA PNG。

較原版減少過大的頭部占比、加長軀幹與腿，使三人的站立輪廓更接近阿明等既有角色。保留角色臉、髮型、服裝、配色與氣質。90年代idle直接採用使用者認可的檔案，並驗證與原樣張內容完全相同。

## 接入規格

沿用 `各風格/characters/正式ID/sprites/動作.png` 結構。請依既有流程轉WebP，順序 idle、run1、run2、jump、spike、dive、win、lose 合成4096×512 atlas。新圖仍使用腳底/輪廓底部錨點(256,496)，面向右；不更改遊戲碰撞盒、速度、跳躍或渲染縮放設定。

站姿可見高度約350px；其他動作依既有阿明同姿勢輪廓比例統一，跪姿落敗另採300px，避免以站姿高度放大跪姿人物。像素圖容許2–4px格點取整，過寬的撲球姿勢以480px寬度上限等比縮放。逐張實際高度與錨點記於manifest。

PC-98與MS-DOS為2倍像素，GB為4倍像素；使用最近鄰縮放，勿平滑插值。PC-98最多15種不透明色加透明、MS-DOS最多63種不透明色加透明，GB使用 #0f380f/#306230/#8bac0f/#9bbc0f 四色加透明。

本包不包含頭像、UI場景或其他角色；也不含阿翼/H02-B03改動。小翠雙馬尾包是另一筆獨立交件，可分別接入。

## 檢查

請檢查選角/對局/勝負畫面使用到的動作atlas，特別是三人的身高一致性、兩張跑步的差異、雙手攔網與單手扣球、水平向右撲球，以及切換風格後腳底位置。主視覺與模式插圖中的其他人物未在本包重畫。

使用內建image_gen生成/修圖，Sharp僅處理切圖、等比縮放、調色盤、像素輸出及驗證。完整提示詞在prompts/，尺寸/透明度/色數/像素格/逐檔SHA-256在manifest.json。
