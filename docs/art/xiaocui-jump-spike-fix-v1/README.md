# 小翠跳躍臉部與殺球縮放補修

12張PNG：六畫風各jump.png、spike.png。這是小翠上一包雙馬尾修正的局部補修。

## 根因與修正

1. jump：舊圖前側手臂穿過額頭，肩膀連接不可讀。內建image_gen重畫成雙臂從左右肩膀向上舉的寬V形，保留完整臉部、雙馬尾與運動服，逐風格重畫。首張候選仍有錯誤，已剔除；prompts.json保留紀錄。
2. spike：原切圖按舊輪廓高度375px縮放，彎腿姿勢把頭和軀幹過度放大。這次沿用原繪圖，以約84%統一等比重輸出，未拉伸、未重畫五官；與站姿/跳躍並排目視比對頭與身體大小，不再以整個輪廓高度代表人體大小。

## 接入

只替換小翠既有4096×512圖集的第4格jump（0-based3）和第5格spike（0-based4）。其他六格請保留現行版本，不得用本包兩格當作完整八格圖集。六畫風皆適用。

所有圖片512×512 RGBA、右向，輪廓底部496。新jump高372px，spike約310–320px；舉手/彎腿造成輪廓高度不同是正常的，不要把spike再次放大到375px。像素格PC98/DOS為2倍，GB為4倍，勿平滑插值。PC98≤15色、DOS≤63色、GB固定四綠色；明細與SHA在manifest.json。

請驗收站姿→跳躍→殺球切換，特別核對頭/軀幹的視覺大小、臉部與肩膀/手臂連接。程式drawSprite使用相同cfg.spriteSize，沒有殺球專用放大；不需更改物理、碰撞盒或全角色縮放。

本包不改頭像、主視覺、其他動作或其他角色。原檔與局部補修完整紀錄在xiaocui-spike-scale-v1工作資料夾。
