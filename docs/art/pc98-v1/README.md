# 虛擬排球王 PC-98 素材包

風格 ID：pc98。回應 requests/2026-10-23-0440-from-claude.md。

181 張正式 PNG：11 位角色各 8 張動作、5 張表情、1 張動作表，另有 27 張球場、球網、排球、特效與介面。10 個操作圖示位於 ui/icons/。原始男角 ID 對應：01-wolf=cangya、02-gambler=jinye、03-prince=leo、04-adventurer=alie。

PC-98 採細緻階梯輪廓、有限色盤與局部棋盤網點；每張最多 15 個實色加透明。角色與表情邏輯尺寸 256×256，以 nearest 2 倍輸出 512×512；8 格動作表是 2048×256，每格 256×256。球場為 480×270 邏輯像素放大 4 倍；其他共用素材皆為交付尺寸的一半、放大 2 倍，詳見 shared-manifest.json。繪製為時代風格詮釋，並非硬體格式 ROM。

角色面向右側，512 圖素的腳底基準為 (256,496)，sheet 每格基準 (128,248)。8 張是 idle/run1/run2/jump/spike/dive/win/lose 關鍵姿勢，並非連續補間動畫。阿翼依 H01-B01 銀色鎧甲造型，保留原服裝，不穿體育服；參考與來源記錄在 references/。

介面主色：背景 #111329、面板 #24203e、文字 #fae8cd、選取 #ffd69a、邊框 #9b80b4。氣氛：深紫視窗、薰衣草雙線框、暖白文字與淡金色選取，搭配薄荷色細節。文字由遊戲繪製，只有 logo 內含「虛擬排球王」。

分數中心 (215,98)/(585,98)，球網近柱白帶頂端 (96,208)，柱底 y=1016（不含）；詳見 layout-metrics.json。球場底部沙地留供角色活動，不內嵌球網或角色。

manifest.json / verification.json 為素材索引與實際檢查結果。overview 圖只供檢視，不算正式圖素。未包含音效或程式；其餘風格的標題場景、模式預覽屬選配，本包由遊戲使用角色圖生成。
