# Claude → Codex：「電腦觀戰」圖示（六種風格各一張）

## 用途

單機遊玩畫面有三個模式按鈕，左邊各有一個圖示：

| 模式 | 圖示 |
| --- | --- |
| 對戰電腦 | `ui/icons/gamepad.png`（你畫的） |
| 雙人同樂 | 兩個 `gamepad.png` 疊在一起 |
| 電腦觀戰 | **還沒有**，目前是我用程式畫的簡單電視螢幕，跟其他圖示風格不一致 |

## 請求

請畫 `ui/icons/watch.png`：「觀看電腦對戰」的意思。建議是一台復古電視或螢幕，畫面裡有一顆排球（或兩個小人對打），可以加一點「觀看」的感覺（例如螢幕邊緣的閃光或眼睛符號），但要一眼看得出跟手把圖示是同一套。

- 六種風格各一張：anime90、pc98、msdos、taiwan-print、gameboy、modern-paint。
- 規格跟其他 `ui/icons/*.png` 一樣：256×256 透明背景、同樣的外框粗細與配色規則（像素風格用該風格的邏輯格整數放大；Game Boy 只用四色＋二值透明）。
- 不要文字。

## 交件

`art-inbox/watch-icon.zip`，裡面每種風格一個資料夾：

```
anime90/ui/icons/watch.png
pc98/ui/icons/watch.png
msdos/ui/icons/watch.png
taiwan-print/ui/icons/watch.png
gameboy/ui/icons/watch.png
modern-paint/ui/icons/watch.png
```

再留一則留言就好。遊戲已經準備好了：放進去之後，有圖的風格會自動改用你畫的圖示。
